# Прокачать осознанность через бот-трекер эмоционального состояния

## Описание и назначение
Трекер тренирует осознанность и внимание: замечать и точно называть своё состояние, и даёт возможность выгружать накопленные данные в личный дневник.

## Как работает
- Несколько раз в день — по времени или по событию — вы отмечаете уровень энергии, эмоцию, контекст.
- Вы можете дополнительно выбрать фокусный вопрос для каждого дня и отвечать на него, пока не отмените выбор.
- В конце каждого дня получаете художественную картину для рефлексии, которая близка к вашей эмоциональной картине дня.
- Раз в неделю получаете картину недели для более глубинного анализа и рефлексии, не только через себя, но и через произведение искусства.

Так ежедневная практика эмоциональной осознанности не только помогает лучше понимать себя, но и становится поводом ближе соприкоснуться с искусством.

## Установка и запуск

Рабочая схема запуска и публикации изменений описана в [OPERATING_GUIDE.md](OPERATING_GUIDE.md).
Это главный документ проекта.

### Требования
- Python 3.8+
- Telegram Bot API token

### Шаги
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/manastasiya-beep/emotional-tracker.git
   cd emotional-tracker
   ```

2. Создайте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` с вашим токеном:
   ```
   BOT_TOKEN=your_token_here
   ```

5. Запустите бота:
   ```bash
   python main.py
   ```

### Production

Для production используйте один облачный Background Worker, подключённый к ветке
`main`, с командой `python main.py` и переменной `BOT_TOKEN`. Не запускайте этот
же токен локально. Точный порядок действий находится в
[OPERATING_GUIDE.md](OPERATING_GUIDE.md).

## Архитектура

- **main.py** — основная логика бота, обработчики команд и сообщений
- **db.py** — работа с базой данных SQLite
- **config.py** — конфигурация, списки эмоций, вопросов, картин
- **keyboards.py** — создание клавиатур и UI элементов
- **rewards.py** — логика выбора картин для ежедневной и еженедельной рефлексии

---

## Структура данных

### Основные таблицы
- **users** — пользователи, их часовые пояса, активные часы
- **entries** — ежедневные отметки (энергия, эмоция, контекст)
- **daily_reflections** — ответы на фокусные вопросы
- **user_daily_focus** — выбранный пользователем фокусный вопрос
- **weekly_rewards** — картины недели и ответы на рефлексивные вопросы

---

## Сценарий использования

1. **Старт**: пользователь вводит `/start`, выбирает активные часы и часовой пояс
2. **Напоминание**: в выбранное время бот отправляет напоминание
3. **Отметка**: пользователь отмечает уровень энергии, эмоцию, контекст
4. **Фокус**: опционально выбирает или подтверждает фокусный вопрос дня
5. **Ежедневная картина**: в конце дня получает картину, соответствующую его состоянию
6. **Еженедельная рефлексия**: раз в неделю получает картину недели и вопросы для глубокой рефлексии
7. **Дневник**: может выгрузить все данные за период в виде CSV
