# Регрессионный чек-лист бота

## Перед запуском

- [ ] `python3 -m py_compile main.py db.py config.py keyboards.py rewards.py`
- [ ] Запущен ровно один процесс бота.
- [ ] В логе нет `Conflict: terminated by other getUpdates request`.

## `/start` и настройка

- [ ] После `/start` виден вопрос про часы и inline-кнопки временных слотов.
- [ ] После выбора слота приходит подтверждение и появляется основное меню.
- [ ] Повторный `/start` не оставляет пользователя без кнопок.

## «Отметить момент»

- [ ] Кнопка открывает выбор энергии.
- [ ] Выбор энергии открывает выбор приятности.
- [ ] Выбор приятности открывает эмоции.
- [ ] Выбор эмоции открывает дополнительный фокус.
- [ ] После выбора фокуса появляется одно сообщение о сохранении и основное меню.
- [ ] Повторная отметка работает в тот же день.

## «Доп. фокус дня»

- [ ] Кнопка открывает список вопросов.
- [ ] Выбор вопроса просит написать ответ.
- [ ] До ответа не появляется лишнее сообщение «Меню».
- [ ] После ответа появляется подтверждение и основное меню.
- [ ] Повторный запуск и сохранение второго ответа работают в тот же день.
- [ ] Отключение фокуса возвращает основное меню.

## После изменений

- [ ] Проверены оба сценария в Telegram вручную.
- [ ] Проверен статус процессов: активен только один `main.py`.

## Коллекция картин

- [ ] У каждой картины уникальный `id`.
- [ ] В каждой зоне есть минимум 8 картин.
- [ ] У каждой картины заполнены `title`, `artist`, `zone` и `url`.
- [ ] Все URL картин открываются и ведут на изображение.
- [ ] При повторных выдачах в одной зоне картина не повторяется сразу.
- [ ] После добавления картин проверены все четыре зоны, а не только одна.
