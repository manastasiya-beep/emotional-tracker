# Регрессионный чек-лист бота

## Перед запуском

- [ ] `python3 -m py_compile main.py db.py config.py keyboards.py rewards.py`
- [ ] Запущен ровно один процесс бота.
- [ ] В логе нет `Conflict: terminated by other getUpdates request`.

## `/start` и настройка

- [ ] После `/start` виден вопрос про часы и inline-кнопки временных слотов.
- [ ] После выбора слота приходит подтверждение и появляется основное меню.
- [ ] Повторный `/start` не оставляет пользователя без кнопок.

## «Отметить момент»

- [ ] Кнопка открывает выбор энергии.
- [ ] Выбор энергии открывает выбор приятности.
- [ ] На выборе приятности есть кнопка «Назад», возвращающая к энергии.
- [ ] Выбор приятности открывает эмоции.
- [ ] На выборе эмоции есть кнопка «Назад», возвращающая к приятности.
- [ ] Выбор эмоции открывает дополнительный фокус.
- [ ] На выборе контекста есть кнопка «Назад», возвращающая к эмоциям.
- [ ] После выбора фокуса появляется одно сообщение о сохранении и основное меню.
- [ ] Кнопка «Посмотреть глубже» сохраняет обычную отметку и открывает три глубоких вопроса.
- [ ] У каждого глубокого вопроса есть кнопки «Пропустить» и «Закончить».
- [ ] После ответа или пропуска открывается следующий вопрос.
- [ ] Вечерняя картина не открывает глубокие вопросы автоматически.
- [ ] Вечерняя картина не открывает дополнительные короткие вопросы автоматически.
- [ ] Ответ на глубокий вопрос сохраняется в `/export` как отдельная запись.
- [ ] Повторная отметка работает в тот же день.

## «Доп. фокус дня»

- [ ] Кнопка открывает список вопросов.
- [ ] Выбор вопроса просит написать ответ.
- [ ] До ответа не появляется лишнее сообщение «Меню».
- [ ] После ответа появляется подтверждение и основное меню.
- [ ] Повторный запуск и сохранение второго ответа работают в тот же день.
- [ ] Отключение фокуса возвращает основное меню.
- [ ] `/export` содержит каждый ответ на дополнительный фокус с вопросом и текстом.

## После изменений

- [ ] Проверены оба сценария в Telegram вручную.
- [ ] Проверен статус процессов: активен только один `main.py`.
- [ ] В логах Railway нет `BadRequest`, `Conflict` или необработанного traceback.
- [ ] При редактировании callback-сообщения используется только inline-клавиатура.
- [ ] Обычное меню отправляется отдельным сообщением с `ReplyKeyboardMarkup`.

## Напоминания и картина дня

- [ ] При активных часах 9–18 напоминания приходят внутри этого окна примерно раз в 2,5 часа.
- [ ] При выключенных напоминаниях ручная отметка всё равно учитывается для картины дня.
- [ ] Для картины дня достаточно одной отметки за локальный день.
- [ ] После картины не приходит автоматический блок дополнительных вопросов.

## Коллекция картин

- [ ] У каждой картины уникальный `id`.
- [ ] В каждой зоне есть минимум 8 картин.
- [ ] У каждой картины заполнены `title`, `artist`, `zone` и `url`.
- [ ] Все URL картин открываются и ведут на изображение.
- [ ] При повторных выдачах в одной зоне картина не повторяется сразу.
- [ ] Если картины текущего сектора за 7 дней закончились, выбор переходит в парный сектор той же группы: `yellow ↔ green` или `red ↔ blue`.
- [ ] При переходе в парный сектор уже показанные картины обеих зон также исключаются.
- [ ] После добавления картин проверены все четыре зоны, а не только одна.
