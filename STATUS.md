# Текущий статус проекта (01.09.2026)

## ✅ Что реализовано

### Основной функционал
- `/start` — инициализация пользователя
- `/help` — справка по командам
- `/hours` — изменить активные часы
- `/timezone` — указать часовой пояс
- `/progress` — статистика за неделю
- `/export` — скачать дневник в CSV
- `/pause` и `/resume` — управление напоминаниями

### Ежедневная рефлексия
- **Отметка состояния**: энергия → приятность → эмоция
- **Фокусный вопрос дня** (НОВОЕ): выбрать один из 4 вопросов и ответить
  - "Что было хорошего?"
  - "Что сегодня удалось?"
  - "Что было важным?"
  - "Что нужно для отдыха?"
- **Ежедневная картина**: в конце дня бот отправляет картину, соответствующую зоне эмоции

### Еженедельная рефлексия
- При 15+ отметках в неделю: "картина недели" + 5 глубоких вопросов
- Вопросы связаны с произведением искусства (metaphorical map approach)

### Интерфейс (УПРОЩЁН)
- Только две кнопки в меню:
  - 📝 Отметить момент
  - 🎯 Доп. фокус дня
- Удалена запутанная кнопка "Как прошёл день?"

### Данные
- SQLite база с таблицами: users, entries, daily_reflections, user_daily_focus, weekly_rewards
- Экспорт в CSV

### Документация
- README.md — полное описание проекта
- project_summary.md — история разработки

### Деплой
- GitHub: https://github.com/manastasiya-beep/emotional-tracker.git
- Production: один облачный Background Worker, подключённый к ветке `main`
- Локальный запуск: только с отдельным тестовым токеном
- Главная инструкция: `OPERATING_GUIDE.md`

## 🤔 FAQ

**Q: Что делать, если production не обновился?**

A: Сначала сравнить commit в GitHub и deployment на выбранном хостинге. Не запускать второй бот локально. Подробный порядок проверки находится в `OPERATING_GUIDE.md`.

**Q: Как добавить новую картину?**  
A: Отредактируй `PAINTINGS` в `config.py`, добавив объект с полями `id`, `zone`, `title`, `artist`, `url`.

**Q: Как изменить вопросы фокуса?**  
A: Отредактируй `DAILY_FOCUS_PROMPTS` в `config.py`.

**Q: Как экспортировать данные?**  
A: Напиши боту `/export` — скачается CSV файл со всеми отметками.
